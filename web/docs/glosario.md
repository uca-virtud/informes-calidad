# Glosario

| Término | Significado |
|---|---|
| ACCUA | Agencia para la Calidad Científica y Universitaria de Andalucía |
| AM | Acción de mejora del plan de mejora |
| Anexo I | Tablas de indicadores del autoinforme |
| Autoinforme de seguimiento | Informe anual en el que el título analiza su funcionamiento |
| CGC | Comisión de Garantía de Calidad del título |
| DEVA | Dirección de Evaluación y Acreditación, de la que procede el modelo de autoinforme |
| ESI | Escuela Superior de Ingeniería |
| FFyL | Facultad de Filosofía y Letras |
| ISGC (P01–P08) | Indicadores del Sistema de Garantía de Calidad, agrupados por procesos |
| LinceBI | Sistema de información estratégica de la UCA, del que se extraen los indicadores |
| MCP | Protocolo que permite a la IA conectarse con sistemas externos, como LinceBI |
| Memoria verificada | Documento oficial del título con sus objetivos y tasas previstas |
| PD | Punto débil |
| PF | Punto fuerte |
| Renovación de la acreditación | Evaluación periódica de todo el periodo desde la última acreditación |
| SGC | Sistema de Garantía de Calidad |
| SI | Sistema de Información de la UCA |
| Skill | Procedimiento escrito que guía a la IA en una tarea concreta |
